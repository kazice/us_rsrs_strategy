# 箱体 / 转折折线看板：口径与使用说明

> 这份文档是**策略研究的基板说明**。看板上的每一条虚线、每一根箭头都由
> `scripts/cand_kline_dashboard.py` 一个文件算出来，口径以本文为准；改常数时同步改本文。
>
> 最后更新：2026-11-23。当前产物：`reports/web/cand_kline_all58.html`（58 期、849 张卡、228 张有箱体）。

---

## 0. 它解决什么问题

每期下探到的候选（板块 RSRS 序 × 板块内换手排名，最多 3×5）各画一张日线图，回答一个问题：
**信号日那天，这只票在箱体的什么位置？是贴着上沿折返，还是从下沿回弹，还是压根没形成箱体？**

有了统一画法，"买点好不好"才有共同的参照系；否则每张图各说各话，结论无法复现。

## 1. 数据与生成

| 项 | 说明 |
|---|---|
| 候选清单 | `reports/etf/<run>/candidates.csv`，只取 `尝试日 == 信号日` 的行（补选日重挑的名单不混进来） |
| 持有区间 | 同目录 `holds.csv`（信号日 / 持有期起 / 持有期止 / 板块 / 个股） |
| 行情 | `data/curated/bars_daily_crsp/symbol=*/part.parquet`，DuckDB 直读（本机没装 pyarrow） |
| 画图窗口 | 信号日前 **63 个交易日**（约 3 个月）+ 持有期 |

**收盘口径（踩过坑）**：CRSP 重建的 bars 里 `close` 是未复权原始价，而 `open/high/low` 与 `adj_close`
已经是同一复权口径。所以收盘一律取 `adj_close`，**只替换 close 这一列**，不能再乘 `adj/close`——
否则开高低会被打成另一个数量级，所有蜡烛都变成阳线。

**指标在全部历史上算完再切窗口**：σ5/σ60 用 60 日半衰期，只在 84 根窗口里算得不到稳定的"常态"。

```powershell
$env:PYTHONIOENCODING="utf-8"; $env:PYTHONUTF8="1"; $env:PYTHONPATH="src"
python -m scripts.cand_kline_dashboard --dir reports/etf/<run> --out reports/web/cand_kline_all58.html
# 只重建指定期（1 起算，逗号分隔）：--only 1,2,3
# 画全部箱体（含下降通道）：--box-slope any
# 副图切换：--sub hh（默认，HH/HL + OBV）| vol（ER20 + σ5/σ60）| adx
# 前导窗口长度：--pre 63
```

## 2. 一张卡片怎么读

| 元素 | 含义 |
|---|---|
| 蜡烛 | 阳（绿）/ 阴（红），基于复权 OHLC |
| MA20 黄 / MA50 蓝 / MA60 紫 / MA200 灰虚 | 趋势闸用的均线 |
| 青虚线 ±2σ + 半透明填充 | 对数价回归通道（箱体）；深绿底 = 这张画出了箱体 |
| 箱体标签 | `上行箱体 N日 · 年化% · 宽% · R² · 触 up/dn · 转折N（↑↓序列）` |
| 绿色箭头折线 | 首端开盘价 → 各转折点 → 识别终点收盘；绿=上行段、红=下行段 |
| 白虚线 | 信号日 |
| 蓝底 + 两侧竖线 | 实际持有区间（熊市期只是当期时间窗，不代表持有该股） |
| 黄实线 | 补选买入日（晚于信号日时才有） |
| 绿点「突破」/ 红点「失守」 | 信号日之后收盘站上/跌破通道，箱体绘制到此为止 |
| 副图（默认） | 上：HH/HL 顶底抬高（ATR 归一化，两者 >0 为合格）；下：OBV 20 日斜率（净流入/成交量，>0 为合格） |
| 卡片右下角 chip | `转折N · ↑下沿回弹 / ↓上沿折返 / 平缓横盘`，只看**最后一个**转折点 |

## 3. 箱体识别（`detect_box`）

对数价做一元线性回归 `ln(close) = a + b·x`，残差标准差 σ，轨道取 `a + b·x ± k·σ`（k=2）。
窗口从 **60 根往回扫到 20 根**，取第一个（=最长）全部合格的——不合格就 continue 试更短的，不是 break。

**准入清单（按代码顺序）**

| 闸 | 阈值 | 作用 |
|---|---|---|
| 宽度 `W = exp(2kσ) − 1` | ≤ 20% | 防极端 |
| 紧度 `tight = W / 窗口内 ATR20% 均值` | ≤ 4.5 | 宽窄用"几个日均振幅"度量，高波动股天然更宽，用绝对百分比会误杀 |
| 首根残差 | ≤ 2σ | 防止窗口起点落在通道外 |
| 后半段最低点抬高 `lf` | ≤ 1.5σ | 底抬高 = 已经向上突破，不算箱体 |
| 后半段最高点压低 `tp` | ≥ −1.5σ | 顶压低 = 已经向下破位 |
| 最深残差 | > −3σ | 中途击穿太深就不是"箱体" |
| 残差符号切换次数 | ≥ 2 | 必须来回过中心线 |
| **宽 > 15% 时另要求 R²** | ≥ 0.25 | 只拦"又宽又没结构"的带子；窄箱体不受约束（水平箱体本来就没有趋势，R²≈0 是正常的） |
| 触轨 | 年化 ≥+15% 要求触上轨 ≥1；≤−15% 要求触下轨 ≥1；中间地带任一侧 ≥1 | 按朝向分开，不要求两边都碰满 |

**成交量不参与判定**：箱体只按价格形态识别。原先有一条"后半段均量/前半段均量 > 1.25 就否决"的闸，
已删除——卡片不画量柱，这条判据在图上完全看不见，且对窗口长度极敏感（同一时点 N=60 量比 1.14、
N=40 就是 1.95）。

**显示层还有一道方向闸**：`--box-slope up`（默认）**只画斜率 ≥0 的箱体**，`b < 0` 整只不画。
下降通道里的"回弹"是反抽，买在反转处难度太大（用户口径）。
典型例子：PSA 2024-03-28 的箱体**识别是成功的**（58 日、宽 7.7%、R² 0.31），但中心线年化 −17%，
`b<0` 所以不画——2026-11-23 用户确认**保持这个行为，不再放宽**。

**触轨次数的口径**：标签里的 `触 up/dn` 数的是残差进入 ±1.5σ 的**独立段数**（`tz=1.5`），
而折线的触轨判定用的是 ±1.9σ（`k − RAIL_TOL`）。两个数不是一回事，读标签时注意。

## 4. 转折折线（`_swing_points`）

四步，缺一不可：

**① 触轨候选**（用影线，不看收盘）
```
z_hi = (ln high − 中心线)/σ  ≥ 1.9  →  触上沿（上沿在 +2σ，容差 0.1σ）
z_lo = (ln low  − 中心线)/σ  ≤ −1.9 →  触下沿
```
盘中冲到轨道又收回去本来就是一次折返，用收盘判会整段漏掉。连续多根贴在同一条轨上只算**一个**点，
取这段里冲得最远的那根；同类型的相邻点再合并成更极端的。

**② 最小摆幅过滤**（`RAIL_MIN_SWING = 1.5σ`）——**触轨只是候选，不等于转折点**。
以上一个已接受的点为参照（窗口第一根算第一个），新候选必须跨出 ≥1.5σ 才收，跨不够就并进参照点。
没有这一步，贴着轨道的一串小波动会把一段趋势切成一串小折线（DG 2021-10-12 最低价只比窗口第一根低
0.1σ，却曾经被当成一个转折点）。

**③ 首端锚点 = 窗口第一根的开盘价**
- 用开盘价不用收盘价：下跌段的顶是那根阴线的开盘价、上升段的底是那根阳线的开盘价，用收盘价会挂在实体外面。
- 不能用轨道价：左端落在通道中部时轨道离价格有 2σ，锚点会变成一个没成交过的价格。
- 若第一个转折点与首端**同侧**（首端本来就压在那边轨上），并入锚点，不单独成点；**异侧必须保留**
  （踩过坑：D 2021-12-09 首端踩下沿、第一个转折点在上沿，被误当重复删掉，折线就贴着下沿走直线）。

**④ 末端锚点 = 识别终点（信号日前一根）的收盘价**
那是决策时点的价格，不是任意切点。末端之后的涨跌不画箭头。

**转折点价格仍取影线极值**（高点=最高价、低点=最低价），因为它们必须落在虚线上——
这是"触轨"的定义。只有首端锚点用开盘价。

## 5. 已知口径与坑

1. **无前视**：箱体只用信号日**前一根**及以前的数据（调仓日当天的跳空属于"箱体之后"，算进去会把通道撑坏，
   OXY 2022-02-24 俄乌跳空是典型）。箱体的绘制部分补到信号日，只是视觉上让它顶住那条白虚线。
2. **熊市卡片是"多头口径对照"**：熊市期只做板块 ETF 或空仓，卡片上的个股不构成持仓依据，蓝底只是时间窗。
3. **0 根箭头不等于没有箱体**：可能是转折点全被 1.5σ 摆幅过滤掉了（平缓横盘、趋势未结束）。
4. **单期可能一个箱体都没有**：所有候选的箱体斜率都为负时，整期一张都不画。
5. **R² 对水平箱体没有意义**：不要用 R² 排序"箱体质量"，它会系统性歧视横盘。
6. **旧产物作废**：`cand_kline.html`、`cand_kline_bounce.html`、`cand_kline_p1.html`、`cand_kline_p10.html`
   都是旧规则的build，只有 `cand_kline_all58.html` 与当前代码一致。

## 6. 常数一览（都在 `scripts/cand_kline_dashboard.py`）

| 常数 | 值 | 位置 | 含义 |
|---|---|---|---|
| `n_min / n_max` | 20 / 60 | `detect_box` 形参 | 箱体窗口长度范围（交易日） |
| `k` | 2.0 | 同上 | 轨道在 ±kσ |
| `tz` | 1.5 | 同上 | 标签里"触轨次数"的判定带 |
| `jump` | 2.0 | 同上 | 首根残差上限（σ） |
| `max_w` | 0.20 | 同上 | 箱体最大宽度（20%） |
| `tight_max` | 4.5 | 同上 | 宽度 / ATR20% 上限 |
| 宽+R² 闸 | 15% / 0.25 | `detect_box` 内部 | 只在宽 > 15% 时要求 R² |
| `lift_max` | 1.5 | 同上 | 后半段底抬高 / 顶压低上限（σ） |
| `RAIL_TOL` | 0.10 | 模块级 | 影线离轨道多近算碰到（σ） |
| `RAIL_MIN_SWING` | 1.5 | 模块级 | 相邻转折点最小摆幅（σ） |
| `--pre` | 63 | 命令行 | 信号日前画多少根 |
