## 0. 结论先行

同一套定稿参数、同一区间（2021-11-15 ~ 2025-12-31，50 期）：

| 版本 | 累计 | 年化 | 波动 | 夏普 | 最大回撤 |
|---|---|---|---|---|---|
| 本地旧口径（yfinance + westock + 快照） | **+637.9%** | 62.7% | 41.1% | 1.524 | −25.8% |
| 只把成分股换成 PIT（`--crsp-scope pool`） | +258.8% | 36.5% | 28.9% | 1.263 | −30.2% |
| 只把换手率/市值/价格换成 CRSP（`--crsp-scope metrics`） | +206.8% | 31.4% | 30.2% | 1.039 | −41.6% |
| **全部换成 CRSP + 手工 GICS 修正板块归属** | **+207.1%** | **31.4%** | 30.7% | **1.023** | −41.6% |
| SPY（同区间） | +54.8% | 11.2% | 18.0% | 0.625 | −24.5% |

- 旧口径（5 年 +2989.5% / 夏普 2.16，含 2026 段）**作废，不要引用**。
- 修正后：年化 31.4%、夏普 1.02、最大回撤 **−41.6%**（比旧口径的 −25.8% 深得多——
  旧口径因为"只买后来变大的赢家"，回撤被系统性掩盖）。仍然跑赢 SPY（11.2%）。
- 两个修正方向高度重合：**都主要作用在"哪些票能进候选池"**，合并后与单独修指标几乎相同。

### 0.1 市值门槛：在正确数据下重扫（结论变了）

| 门槛 | 累计 | 年化 | 夏普 | 最大回撤 |
|---|---|---|---|---|
| 100 亿美元 | +234.7% | 34.2% | **1.083** | −34.1% |
| 200 亿美元 | +116.8% | 20.7% | 0.684 | −33.5% |
| 300 亿美元 | +118.5% | 21.0% | 0.644 | −40.8% |
| **500 亿美元（当时定稿，现仍是这个门槛）** | +207.1% | 31.4% | 1.023 | −41.6% |

仍然不单调（旧口径是"500 最好、300 最差"，现在是"100 最好、300 最差"）。
**"500 亿最好"这条结论不成立了**：500 亿的夏普比 100 亿低 0.06、回撤深 7.5 个百分点。

不过门槛的原始理由没变也没被推翻——它是**数据清洗口径**（剔除换手率分母失真的小盘票）。
值得注意的是：这个理由本身是"用坏数据时的补丁"，CRSP 给了真实的总股本，
分母失真这一层问题已经消失，所以 100 亿档表现反超并不意外。
**默认仍用 500 亿**（不与实盘脱钩、不按收益挑参数），但要不要按新证据调整，属于需求方决策。

### 0.2 从 ticker 视图迁到池层：只有 4 期选股变了

同一区间、同一套参数，把数据层从「ticker 口径的 CRSP 视图」换成「security_id 主键的池层」，
50 期里 **46 期选股完全相同**，差的是：

| 信号日 | 旧 | 新 | 差异来源 |
|---|---|---|---|
| 2023-02-28 | NVDA | META | META 改名（FB→META）前的价格历史，池层按 security_id 连通 |
| 2024-11-29 | TSLA | PLTR | 新纳入票的成分期前换手率（外部补齐）→ `turn120` 从缺值变成有值 |
| 2025-06-30 | MU | COIN | 同上，排序分 `turn20²/turn120` 在补数后重排 |
| 2025-11-28 | GS | WBD | 同上，且触发了牛市补选（信号日无票 → 12-11 买入） |

结论：+207.1% → +269.4% 的差别不是策略改动，而是「刚纳入指数的票在前几个月不再缺指标」。
旧视图里这些票的 MA200 / turn120 是 NaN，于是被趋势闸或 `turn_rank_mode=ratio` 挡掉。

## 2. 四项对账（错误定位）

### ① 成分股：幸存者偏差是主因

| 月末 | CRSP 当期成分 | 快照里有·当时不是成分 | 当时是成分·快照里没有 |
|---|---|---|---|
| 2021-11-30 | 505 | 85 | 87 |
| 2023-03-31 | 503 | 66 | 66 |
| 2024-07-31 | 503 | 49 | 49 |
| 2025-11-30 | 503 | 29 | 29 |

- 平均每期**混入 58 只"当时还没进指数"的票**（APP、PLTR、SMCI、AXON、COIN、UBER、VST…），
  这些票恰恰是 2023-2025 涨幅最大的一批 → 直接造成收益虚高。
- 平均每期**漏掉 58 只当时还是成分的票**（AAL、ATVI、CERN、DISH、FRC、HES、K、LUMN…），
  其中大量是走弱的票 → 漏掉它们等于只留下赢家。
- 全区间里"当过成分、但今天的快照里没有"的票共 **98 只**，旧口径**永远买不到**。

### ② 换手率：中位数完全一致，只有多股本结构的票错了

可比样本 451,736 个（symbol×日），比值 = 本地 / CRSP：

| 年份 | 中位比值 | ±10% 占比 |
|---|---|---|
| 2021 | 1.000 | 94.6% |
| 2022 | 1.000 | 94.5% |
| 2023 | 1.000 | 95.1% |
| 2024 | 1.002 | 95.3% |
| 2025 | 1.002 | 94.9% |

**结论：换手率整体没问题**，但少数票系统性偏低——本地用「全公司总股本」当分母，
而成交量只是某一个股份类别：

| 代码 | 本地/CRSP | 原因 |
|---|---|---|
| NWS / NWSA | 0.33 / 0.68 | B 类股成交量 ÷ 全公司股本 |
| GOOG / GOOGL | 0.46 / 0.47 | A/C 类股分开计成交量 |
| FOX / FOXA | 0.53 / 0.52 | 同上 |
| DELL | 0.50 | 双重股权 |
| EL / RL / HSY | 0.65 / 0.64 / 0.73 | 期间股本大幅变动（回购），本地股本滞后 |

这些票在旧口径里换手率被压低 → 排序靠后 → 不会因为"过于活跃"被 `--turn-cap 0.20` 剔除。

### ③ 市值：1% 的票日会在 500 亿门槛上判反

本地反推口径（成交量 ÷ 换手率 × 价格）vs CRSP `DlyCap`：中位比值 1.000，±10% 占 94.6%。
但门槛附近（0.5~2 倍）的 205,046 个样本里，**判定翻转 2,042 个（1.0%）**：

| 代码 | 翻转天数 | 原因 |
|---|---|---|
| APH | 381 | 期间拆股，本地股本未同步 |
| DELL | 296 | 双重股权 |
| EL | 208 | 回购导致股本跳变 |
| CHTR / WDAY / HSY | 85 / 84 / 71 | 同上 |

单看比例不大，但它们集中在"边缘票"上，而策略每期只在 3 个板块 × 前 3 名里挑，边缘票的改变足以换掉整个持仓。

### ④ 价格：本地行情没问题

本地 `adj_close` vs CRSP `收盘 ÷ 累计复权因子`：日收益中位绝对差 0.00000，P99 0.0030，
相关系数中位 1.000，**没有一只低于 0.95**。拆股、分红口径两边一致。

> 踩过一个坑：CRSP 的 `DlyCumFacPr` 是**除数**不是乘数。ORLY 15:1 拆股当天收盘
> 1348.10 → 91.71、因子 15.0 → 1.0，`close / facpr` 才连续（89.87 ≈ 91.71）。
> 一开始写成 `close × facpr`，ORLY/WMT/CPRT 的收益相关性只有 0.38~0.43。

- **板块归属**：三级——① `config/ref/us_sector_holdings.csv`（当前快照）；② 手工 GICS 表
  `crsp.SECTOR_OVERRIDE`（25 只历史成分股，SIC 会分错的媒体/软件/医药/REIT）；③ SIC 大类映射。
  体检结果：581 只池子里 **68 只仍靠 SIC 近似**，50 期里只有 1 只（PXD，SIC 1311 → XLE，无歧义）
  被真正选中，**近似层对结论已无实质影响**（`python -m scripts.audit_crsp_coverage` 可复核）。
- 保留 `--data-source local`，旧口径随时可复现对照，但**不再作为结论引用**。

## 4. 复现

```powershell
$env:PYTHONPATH = "src"

# 修正口径（推荐）
python -m scripts.sector_stock_rsrs --data-source crsp --n 20 --m 40 --pick turnma `
  --trend-mode strong --trend-stack 20,60 --stack-slope 5 --slope-mas 20,60 `
  --trend-above 50 --trend-cross 50,200 --adx-min 20 --turn-shares ws --turn-rank-mode ratio `
  --bull-refill --turn-cap 0.20 --turn-tail 0.48 --min-mcap 500 --regime-ma 200 `
  --regime-bear nofilter --regime-window 21 --bear-etf-only --bear-min-score 0 `
  --bear-rank both --bear-intersect-top 3 --bear-slope-window 120 `
  --start 2021-11-13 --end 2025-12-31 --tag crsp

# 归因（只换成分股 / 只换指标）
#   加 --crsp-scope pool  或  --crsp-scope metrics
```

对账基准：**+207.1% / 年化 31.4% / 夏普 1.023 / 回撤 −41.6%**，50 期，选股跑赢 ETF 31/50（累计选股差 +87.0%）。

> 逐期收益已改为含「持有期起」当日（含当日换手成本），连乘严格等于 `nav_daily` 全区间收益；
> 因此选股差类数值与早期快照略有差异，累计/年化/夏普/回撤不受影响。
